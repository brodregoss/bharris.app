# Last Minute Study

Single Expo/React Native app at the repo root. No nested app folders.

## Commands

```bash
npm install
npm run ios          # daily dev
npm run prebuild:ios # generate ios/ for Xcode
npm run xcode        # open in Xcode
```

## Key paths

- `app/` — expo-router screens
- `src/core/studyUtils.ts` — cram algorithm (do not rewrite casually)
- `src/engine/` — Smart Cram (future); not used in Step 1 flow
- `_archive/` — legacy web + old study app; reference only

## Base44

Credentials in `.env.local` (`EXPO_PUBLIC_BASE44_*`).
